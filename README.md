# Dự án: Hệ thống Hỗ trợ Tutor – HCMUT

## Giới thiệu

Hệ thống Hỗ trợ Tutor được xây dựng trong khuôn khổ môn học tại Khoa Khoa học và Kỹ thuật Máy tính - Trường Đại học Bách Khoa nhằm quản lý và vận hành chương trình Tutor/Mentor hiệu quả hơn. Ứng dụng hỗ trợ đăng ký chương trình, ghép đôi tutor–mentee, lập lịch buổi tư vấn, theo dõi tiến bộ, đánh giá và báo cáo. Hệ thống tích hợp các dịch vụ nội bộ HCMUT như **HCMUT_SSO**, **HCMUT_DATACORE**, **HCMUT_LIBRARY**, đồng thời hỗ trợ các tính năng nâng cao như AI matching và hỏi đáp dựa trên tài liệu (RAG).

Công nghệ sử dụng: **Next.js**, **Node.js**, **PostgreSQL**, **Socket.io**, và các dịch vụ tích hợp của trường.

# Quick Start

## Phát triển (Development)

```bash
npm install
npm run dev
```

Mở trình duyệt và truy cập:
**[http://localhost:3000](http://localhost:3000)**

## Deploy

Triển khai bằng **Render** và truy cập tại
[https://hcmuttutor.onrender.com/](https://hcmuttutor.onrender.com/)
